# Contributing to MYCELIUM

MYCELIUM is a GPL-3.0-only firmware for the M-VAVE FM-1, a derivative of
[SLOOP](https://github.com/isod89/sloop-fm1) and [Felucca](https://github.com/hugelton/Felucca).
Contributions are welcome under the same licence (see `LICENSING.md`).

## The loop

```sh
# once
pip3 install Pillow
tools/get_toolchain.sh          # JieLi clang for the pi32v2 (Linux x86-64; Docker on macOS)
tools/get_sdk_files.sh          # three AC79 SDK files (or clone the SDK, see BUILDING.md)

# every time
./build.sh                      # -> build/felucca.fwsc (fails on what would overflow flash)
sh tests/run_tests.sh           # every host test: no hardware needed
```

Hear a sound without a device: `build/host/hostsim ENGINE PRESET MONO out.wav`
(engines 0 ANALOG, 1 DIGITAL; `tests/run_tests.sh` builds it). Install on the FM-1 with
`python3 tools/fm1_install.py build/felucca.fwsc` — at your own risk.

## Invariants that must not break

- Parameters: new common parameters go **just before `P_E0`** in `firmware/src/core.h`;
  user presets and saved projects map parameters by count, inserting elsewhere corrupts them.
- Presets (`preset_t` tables in `firmware/src/eng_*.c`): every factory sound needs a level
  trim so it is as loud as the others: indices inside the first 16 go to `preset_trim.h`
  (generated by `tools/level_presets.py`), Mycelium additions to `mycelium_trim.h`
  (measured with `tests/mycelium_preset_level.c`).
- The browsable bank: a preset added to `BANK[]` in `firmware/src/ui.c` must match its name
  exactly and live in engine 0 or 1 (`tests/ui_pages_test.c` fails otherwise); mirror new
  entries in `meta/MYCELIUM-SOUNDBANK.json`.
- Renders are regression-tested by hash: after an **intended** change of a sound,
  `GOLDEN_UPDATE=1 sh tests/run_tests.sh`, review the diff of `tests/golden.txt` and commit
  it with the change. After an intended change of CPU cost, `BUDGET_UPDATE=1`.
- Flash budget: `tools/build.py` refuses an app that overflows `APP_SLOT`, RAM or BSS.

## Sound submissions

Factory sounds are original designs. Do not submit or paste third-party preset data
(Serum, Vital, DX7 banks, .fxp / .vital / sysex dumps): describe the sound you want instead
(engine, ADSR, movement, reference track). Samples must be CC0 with provenance recorded next
to them.

## Pull requests

- One sound pack or one fix per PR; describe what you heard on the host render.
- CI runs `./build.sh` and `sh tests/run_tests.sh` on every push: keep it green.
- `git log --oneline` should read like a changelog; every source file keeps its
  `SPDX-License-Identifier` header.
