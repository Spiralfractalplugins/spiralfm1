# SPIRALFM1 для M-VAVE FM-1 - 1.0

Forest, Goa, Psytrance, Hitech и техно для M-VAVE FM-1.
Самостоятельная прошивка от Spiralfractal: построена на Mycelium 1.0 (Mandalars), который сам
по себе основан на SLOOP/Felucca. Прошивка распространяется под GPL-3.0-only, упоминания
происхождения сохранены.
SPIRALFM1 приносит собственный знак (спираль вместо мицелия), переименованные и перенастроенные
фабричные пресеты и заново синтезированные удары барабанов; грувы, песни и работа PSY FX — из
Mycelium 1.0.

Держать HOME → GROOVES → выбрать грув → OCT+ → OCT+ для подтверждения.
Сначала сохраните свою работу: загрузка заменяет текущий луп и его звуки, но не сохранённые
слоты проектов. Транспорт и запись должны быть остановлены. Затем сыграйте любую клавишу:
бит стартует. После осознанного STOP PLAY запускает его заново.
Обновление никогда не заменяет сохранённую сцену: новый грув надо загрузить явно.

Шесть грувов, по 32 шага: FOREST JAM 156 BPM, PSY ROLL 148,
PSY GALLOP 146, GOA ACID 144, HITECH 196, TEKK 170.
Forest: четверстные кики, три шестнадцатые баса между ними, офбит-хэты, без снейра.
TeKK: офбит-бас, четверстные кики с филлом в конце, экономная хлопушка.
Загрузка снимает соло и восстанавливает уровень барабанов и состояния фильтров.

Короткое нажатие ARP: GALLOP → OFFBEAT → FULL-ON. Заменяет только партию баса;
основная нота, остальные дорожки, темп и работающий транспорт остаются как были.
Переключение заблокировано во время записи / отсчёта или при активном арранжере.
Долгое нажатие ARP по-прежнему даёт roll.

Короткое нажатие FX с отпусканием открывает PSY FX:
1 KB LP: один общий низкочастотный фильтр для сухого баса на дорожке 1 и нот кика 35/36.
  Слева открыт, справа закрыт; фиксированный резонанс 25/127, примерно двадцать процентов.
2 SPACE: синхронизированное эхо и реверб вместе, посылы для лида и FX.
  На 0 ничего новое не подаётся; хвосты реверба затухают сами.
3 FB+DRV: обратная связь эха и низкочастотный драйв вместе; слева оба 0,
  справа обратная связь 100/127 и драйв 127/127 (3x мягкое насыщение перед фильтром).
4 ALIEN: кольцевая модуляция только на сухом лиде и FX (дорожки 2/3).
  Слева обход, справа металлическая модуляция до 2400 Гц; сглаженная интенсивность.
  Кик, бас и все барабаны остаются нетронутыми. Посылы эха / реверба остаются отдельными.
Долгое нажатие FX по-прежнему даёт панч-эффекты. Формат проекта остаётся совместимым.

21 отобранный фабричный пресет; три разных набора барабанов: Psy / Forest / Hitech.
Наборы собраны из 15 процедурно синтезированных ударов
(`tools/gen_spiral_drums.py`): осцилляторы, огибающие высоты тона, шум и насыщение,
фиксированные seeds, моно PCM16 44,1 кГц. Происхождение и хэши:
assets/spiralfm1/samples/SOURCE.json, DRUM-SOURCES.json и ORIGINAL-SOUNDS.json.
Прежний подбор Mycelium опирался на купленные удары Loopmasters; он полностью заменён
собственным синтезом. Права распространения базы прошивки помечены отдельно
(банк звуков CC0, см. LICENSING.md).

Собственный логотип-спираль SPIRALFM1 при запуске (нарисован tools/gen_spiralfm1_svg.py),
тёмный фон.
Дорожки 1-4: неоновый зелёный, бирюзовый, неоновый жёлтый, неоновый розовый.
USB-имя SPIRALFM1, производитель Spiralfractal. Знак, словесный знак и графика — собственные
разработки.
USB / TRS MIDI: каналы 1-3 для синтезаторов, канал 10 для барабанов, канал 4 для выбранной
дорожки. Ноты, velocity, clock / start / stop; обычные CC управления звуком не реализованы.
GLO → SYSTEM → SYNC выбирает USB / TRS / INT.

Проверено: бюджет памяти и процессора, секвенсор, автостарт, меню, FX, смена баса,
наборы барабанов, TeKK и 20 000 случайных нажатий интерфейса. 18 контрольных аудиорендеров
на настоящем синтезе хоста, без перегруженных сэмплов; записей с устройства нет.
Прослушивание и проверка работы на FM-1 ещё предстоят после установки.
Обучающие ролики Dash-Glitch воспроизведены не дословно; никакого сотрудничества не утверждается.
Перед любой публичной публикацией проверите унаследованные лицензии на ассеты и соответствие GPL.

## Новая техника исполнения в 0.14
Коротко ENV: огибающая звука. Держать ENV не менее 0,7 секунды: временный psy-филл
с хэтами и хлопушками, только при идущем бите. Отпускание заканчивает филл без
изменения партий. Коротко LFO: модуляция. Держать LFO не менее 0,7 секунды:
партии FOREST / GOA / HITECH для лида и FX по кругу. Заменяются только эти
две партии; свою работу сначала сохраните. Бас, барабаны и темп остаются.
Запись / отсчёт и активный арранжер песни блокируют оба действия с удержанием.
Держать HOME → LOGO → OCT+: посмотреть исходный логотип, OCT- назад в меню.
PSY FX постоянно показывает последнюю повёрнутую ручку крупно, с неоновой
шкалой и подписью цели, даже когда ZOOM выключен.

## Вероятность и заставка в 0.15
HOME / обзор дорожек, дорожки 2 и 3: KNOB 1 PROB, отдельно для каждой дорожки.
100 процентов играет каждый запрограммированный NOTE-шаг; 0 процентов — ни одного; в промежутке
каждый NOTE-шаг решается заново. Аккорды и рэтчеты попадают в это решение вместе.
Пропущенные шаги не вызывают рэтчет, лиги не бросаются повторно. Партрия не стирается.
Сыгранные напрямую ноты остаются играбельными; бас и барабаны ворота вероятности не получают.
Хранится в существующем параметре P_APROB, который использует и арпеджиатор.
Фабричные пресеты стартуют со 100 процентов; смена звука может сбросить этот параметр звука.
На басе / барабанах KNOB 1 в обзоре дорожек остаётся глобальным свингом.
При включении логотип SPIRALFM1 держится около четырёх секунд.
Watchdog во время этого экрана регулярно обслуживается.

## Последняя тестовая версия 0.16
После установки: сначала сохраните свою работу, затем загрузите новый фабричный грув или заново
выберите фабричные пресеты. Иначе сохранённые сцены продолжат нести свои старые параметры.
Обновление не заменяет сохранённые проекты.
Бас: дорожка 1 → коротко ENV → ATK/DEC/SUS/REL.
Кик: дорожка 4 → коротко ENV → ATK/DEC/SUS/REL. Первый поворот включает отдельную
огибающую кика и начинается с attack 0, decay 70, sustain 127, release 127.
Огибающая кика действует только на ноты 35/36, не на хэты / хлопушки / снейры. Без включения
сэмпловые кики остаются как есть. Повторные кики перезапускают огибающую.
Release следует за note-off или автоматическим гейтом one-shot: четверть ноты в текущем
темпе, умноженная на существующее значение drum GATE (SGATE/128).
Удержание ENV остаётся временным psy-филлом, короткое нажатие открывает огибающую.
FX KNOB 4 ALIEN+: кольцевая модуляция и стаккато вместе на лиде и FX. Глубина растёт
с 0 до 127, сетка стакато переключается 1/8 → 1/16 → 1/32. Ручка 0 выключает стакато.
Заимствует настройки слайсера дорожек 2/3; бас и барабаны остаются в стороне.
Переработаны 16 огибающих лида / FX / атмосфер: длиннее хвосты, слышимый sustain
у лидов и быстрее attack у атмосфер. Перкуссионные удары остаются с sustain 0.
Все 21 пресет измерены заново, индивидуальные подстройки уровня исправлены с целью
-20 LUFS и запасом по пику. Проверки на хосте пройдены; физическое прослушивание и
проверка работы Ларсом ещё не сделаны.

## Текущее состояние 1.0: свои барабаны и эпические песни
Исторический набор LTWB / Loopmasters в этой ревизии заменён.
15 собственных барабанов: осцилляторы, огибающие высоты тона, шум и насыщение.
Генератор и провенанс SHA256 в tools/gen_spiral_drums.py и
assets/spiralfm1/samples/ORIGINAL-SOUNDS.json.
Внешних аудиовходов нет. Дополнительный хип-хоп пак больше не в дереве исходников релиза.
База прошивки под GPL и отдельно помеченный банк звуков CC0 сохраняются.
Держать HOME → SONGS: Forest Odyssey / Psy Ascension / Tekk Reactor / Hitech Portal.
Каждая песня 240 тактов, 16 секций; A атмосфера, B развитие, C дроп, D брейк.
Виртуальные сцены не перезаписывают слоты проектов. USER SONG восстанавливает свой порядок.
Фабричные песни доступны только на чтение; после перезапуска выбирать заново.
Держать ARP не менее 700 мс: режим roll и логотип фиксируются. Ещё раз ARP: выйти без смены баса.
Сыгранные ноты гонят roll, только пока их клавиша удерживается. Проверены четыре целые песни и
фазз интерфейса.
На устройство ещё не установлено; нужно новое физическое прослушивание.

Установка: текущий пакет 1.0 передан полностью, перезапуск и работающая MIDI-идентификация
устройства проверены. Собственные барабаны, песни и ARP-лэтч установлены; физическое
прослушивание новых функций ещё не сделано.

## Прямое SAVE и дисторшн
Коротко SAVE из обзора, со страницы барабанов или из SONG: четыре готовых банка фабричных песен.
USER SONG открывает свои секции; там EDIT, чтобы сохранить цепочку. KNOB 4 в TRACKS:
P_DIST для баса / барабанов, P_PAN для синтезаторных дорожек 2/3. Drum KIT KNOB 4: P_DIST,
drum GRID по-прежнему хранит уровень удара. Барабанная дисторшн стоит до пана / реверба и до
фильтра кика / баса, а нулевое значение ничего не меняет. FX KNOB 4 остаётся ALIEN+.
Шесть грувов проверены на максимальной басовой и барабанной дисторшн без клиппинга.

## MODERN MOTION: 16 новых фабричных пресетов
Десять лет современных клубных звуков софтовых синтезаторов на FM-1: восемь ANALOG и восемь
DIGITAL (FM) пресетов по характеру басов с движением, вобблов, гроулов, райзеров, лидов большого
зала и стеклянных плуков из Vital и Serum 2 — собственные разработки, импортированных данных
пресетов нет (лицензии этих синтезаторов импорт не разрешают; упоминается только направление
звука). ANALOG 21-28: MODERN PLUCK, GROWL VA, BIG ROOM LD, TRANCE RISE, DARK MOTION,
MIDNIGHT PAD, VAPOR KEY, TECH SNAP. DIGITAL 29-36: FM WOBBLE, MODERN GROWL, GLASS PLUCK,
CINEMA HIT, NEON SHIM, RISER FX, VOCAL FM, DROP SUB. Все 16 есть в отобранном браузере BANK
устройства (ручка PRESETS) и записаны в meta/SPIRALFM1-SOUNDBANK.json; подстройки уровня
измерены tests/spiralfm1_preset_level.c (BS.1770, цель -20 LUFS, как в 0.16), проверка —
tests/spiralfm1_motion_pack_test.c в tests/run_tests.sh.

## SPIRALFM1 1.0: собственный знак, перенастроенные звуки, новые барабаны
Самостоятельная версия вместо форка: имя, словесный знак и спираль нарисованы заново
(`tools/gen_spiralfm1_svg.py`, `tools/gen_spiralfm1_logo.py`), USB-продукт "SPIRALFM1",
производитель "Spiralfractal", заголовок в меню и строка на заставке "BASED ON MYCELIUM".
Переименовано одинаково везде: SYSTEM/ABOUT пишет "MYCELIUM / SLOOP / FELUCCA" под собственным
именем, восстановление показывает "SPIRALFM1 USB RESCUE", редактор сообщает "SPIRALFM1 1.0" как
идентичность движка, веб-редактор и установщик несут новое имя (их футеры сохраняют
происхождение), а пакет называется `spiralfm1-<version>.fwsc`.

Банк звуков: фабричные пресеты с грибными и лесными названиями теперь названы в честь спирали, и
каждый звук дополнительно перенастроен (выбор алгоритма и отношений, индекс модуляции, огибающие,
цель, скорость и форма LFO, посылы FX; у ANALOG — смесь осцилляторов, cutoff, резонанс и
дисторшн):

| Mycelium 1.0 | SPIRALFM1 1.0 |
| --- | --- |
| ROOT BASS | SPIRAL BASS |
| SPORE TALK | VORTEX TALK |
| HYPHA BLIP | PHASE BLIP |
| BARK GROWL | ORBIT GROWL |
| MOSS DRONE | HELIX DRONE |
| GILL METAL | TORUS METAL |
| FUNGAL DROP | FRACTAL DROP |
| NIGHT SPORE | NIGHT WHORL |
| ACID FOAM | ACID COIL |
| SWAMP CHIRP | PHASE CHIRP |
| SWAMP SQ | VORTEX SQ |
| SPORE BURST | COIL BURST |

Паки MODERN MOTION (ANALOG и DIGITAL) сохраняют имена, но тоже перенастроены;
PSY BASS, HI BASS, GOA ACID, PSY KICK, METAL HIT, RUST IMPACT, HITECH ZAP, LASER FALL и
LIQUID FM остаются, с исправленными значениями.

Барабаны: все 15 ударов синтезированы заново — кик с FM-боковой полосой вместо шумового клика,
металл из четырёх обертонов для хэтов, хлопушки, сформированные полосовым фильтром, снейр в два
тона. У каждой роли своя цель по пику; все наборы держатся в пределах примерно 1 дБ от прежней
громкости, а спектральный баланс хай-хэта и снейра остаётся открытым сверху.

Громкость: все пресеты измерены заново (`tests/spiralfm1_preset_level.c`, BS.1770, цель
-20 LUFS), подстройки в `firmware/src/spiralfm1_trim.h`. Золотые рендеры, проверки интерфейса и
песен и прогон на шум обновлены под новые звуки (`sh tests/run_tests.sh`).
